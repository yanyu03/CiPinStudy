# 抓取与清洗增强（v1.1 起步）

本次改动先把「抓取 -> 清洗 -> 结构化收录」基础打牢，重点在格式化输出，便于后续分析和归档。

## 已完成能力

1. **抓取清洗**
   - 标题标准化：去掉前缀标签（如【xx】/ [xx] / (xx)）并压缩空白。
   - URL 标准化：统一绝对地址，移除 hash 与常见追踪参数。
   - 日期提取增强：支持多种 URL 日期模式。
   - 时间窗过滤：`crawlNews({ limit_hours })` 现在会按小时窗口过滤历史文章。

2. **收录与格式化**
   - 采集结果新增 `cleaned_at`、`collection_notes` 元信息。
   - 自动生成 `markdown_digest`（关键词 + 文章列表），可直接归档到笔记系统。
   - 新增 `getFormattedCollection()`：同时返回 JSON 结构与 Markdown 文本。

## 建议下一步

- 增加“导出 JSON / Markdown”按钮到设置页。
- 给 `collection_notes` 加上规则版本号（便于回溯）。
- 将关键词清洗从停用词升级到词性/实体级清洗。
